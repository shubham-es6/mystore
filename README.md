# MYStore

A modern e-commerce web application built with React, Vite, and Tailwind CSS.

## 🚀 Tech Stack

- React.js
- JavaScript
- Vite
- Tailwind CSS
- ESLint

## ⚙️ Development Setup

- Vite development server
- Development port: `3000`
- Tailwind CSS configured with Vite
- Custom MYStore favicon and page title
